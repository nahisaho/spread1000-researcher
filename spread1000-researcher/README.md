# SPReAD-1000 Researcher Survey Suite

文部省の革新的研究推進プログラム **SPReAD-1000** の申請者を対象とした研究者サーベイ・評価スイート。

## 概要

研究者名と所属機関を入力すると、Web 検索で公開情報を収集し、6 軸 × 5 段階で総合評価レポートを生成します。

## 評価軸

| # | 軸 | 内容 |
|---|-----|------|
| 1 | 研究実績 | 論文数・被引用数・掲載誌の質 |
| 2 | 外部資金獲得 | 競争的資金の規模・件数 |
| 3 | 研究の革新性 | 新規性・独自手法・分野開拓 |
| 4 | 国際的活動 | 国際共著・海外連携・招待講演 |
| 5 | 学際性・波及効果 | 分野横断・社会実装・産学連携 |
| 6 | キャリア段階 | 段階に応じた相対評価・将来性 |

## Sub-skills

| Skill | 役割 |
|-------|------|
| `spread1000-researcher-survey` | Web 検索による情報収集 |
| `spread1000-researcher-evaluate` | 6 軸 5 段階スコアリング |
| `spread1000-researcher-report` | 構造化評価レポート生成 |

## ワークフロー

```
Phase 0: 研究者同定（名前・所属確認）
Phase 1: サーベイ（情報収集）⏸️ エビデンス承認
Phase 2: 評価（6軸スコアリング）
Phase 3: レポート生成
```
