# SPReAD-1000 Researcher Survey

文部省の革新的研究推進プログラム **SPReAD-1000** 申請者を対象とした研究者サーベイ・評価 Agent Skills スイート。

研究者名と所属機関を入力すると、Web 検索で公開情報を収集し、**6 軸 × 5 段階**で総合評価レポートを自動生成します。

## インストール

```bash
npm install @nahisaho/spread1000-researcher
```

`postinstall` により `.github/` 配下にスキルが自動配置され、GitHub Copilot から即座に利用可能になります。

## 評価軸

申請者を以下の 6 軸で多面的に評価します。各軸は 1〜5 の 5 段階でスコアリングされます。

### 軸 1: 研究実績（Research Output）

論文数・被引用数・掲載誌の質を評価します。

| スコア | 評価 | 基準 |
|--------|------|------|
| 5 | 卓越 | トップジャーナル（Nature/Science 級）に複数掲載。被引用数が分野上位 5% |
| 4 | 優秀 | 主要国際誌に継続的に発表。複数の高インパクト論文 |
| 3 | 良好 | 査読付き論文を安定的に発表。分野内で一定の認知度 |
| 2 | 発展途上 | 論文数が限定的 |
| 1 | 要改善 | 査読付き論文がほとんど確認できない |

### 軸 2: 外部資金獲得（Funding Track Record）

競争的資金の獲得規模・件数を評価します。

| スコア | 評価 | 基準 |
|--------|------|------|
| 5 | 卓越 | 大型資金（科研費基盤 A/S、CREST、ERATO 等）の PI 実績 |
| 4 | 優秀 | 中規模資金（科研費基盤 B、さきがけ、AMED 等）の獲得 |
| 3 | 良好 | 小〜中規模資金（科研費若手、挑戦的研究、民間助成）の獲得 |
| 2 | 発展途上 | 学内資金・少額助成のみ |
| 1 | 要改善 | 外部資金の獲得実績が確認できない |

### 軸 3: 研究の革新性（Innovation Potential）

新規性・独自手法・分野開拓の可能性を評価します。

| スコア | 評価 | 基準 |
|--------|------|------|
| 5 | 卓越 | 新分野を開拓。パラダイムシフトの可能性。特許・新技術の創出 |
| 4 | 優秀 | 既存分野に新手法・新視点を導入 |
| 3 | 良好 | 着実な研究進展。一定の独自性 |
| 2 | 発展途上 | 既存手法の適用が主 |
| 1 | 要改善 | 革新的要素が見当たらない |

### 軸 4: 国際的活動（International Engagement）

国際共著・海外連携・招待講演など、グローバルな研究ネットワークを評価します。

| スコア | 評価 | 基準 |
|--------|------|------|
| 5 | 卓越 | 国際的な研究ネットワークのハブ。主要国際会議の基調講演・組織委員 |
| 4 | 優秀 | 海外機関との継続的共同研究。国際会議での招待講演 |
| 3 | 良好 | 国際共著論文あり。国際会議での発表実績 |
| 2 | 発展途上 | 国際活動が限定的 |
| 1 | 要改善 | 国際的な活動が確認できない |

### 軸 5: 学際性・波及効果（Interdisciplinary Impact）

分野横断的な研究展開、社会実装・産学連携の実績を評価します。

| スコア | 評価 | 基準 |
|--------|------|------|
| 5 | 卓越 | 複数分野を橋渡し。社会実装・政策提言の実績。大規模産学連携 |
| 4 | 優秀 | 隣接分野との共同研究。産学連携や社会実装の試み |
| 3 | 良好 | 分野内に留まるが、応用展開の可能性を示す |
| 2 | 発展途上 | 単一分野に特化 |
| 1 | 要改善 | 分野横断・応用展開の兆候なし |

### 軸 6: キャリア段階（Career Stage & Trajectory）

キャリアステージに応じた相対評価を行います。若手なら将来性、シニアなら指導実績・組織運営も考慮します。

| スコア | Early（若手） | Mid（中堅） | Senior（シニア） |
|--------|--------------|-------------|-----------------|
| 5 | 早期から顕著な成果。将来性が極めて高い | 分野リーダーへの成長軌道 | 分野の権威。後進育成で卓越 |
| 4 | 段階に比して優れた実績 | 独自の研究路線を確立 | 豊富な実績と組織貢献 |
| 3 | 段階相応の堅実な成長 | 安定した研究活動 | 継続的な研究活動 |
| 2 | 実績がやや少ない | 成長が停滞気味 | 近年の活動が減少 |
| 1 | 実績が乏しい | 長期間成果が出ていない | 研究活動がほぼ停止 |

## 総合評価

6 軸のスコアから総合ランクを算出します。証拠が不十分な軸（Confidence: low）は除外されます。

| ランク | 平均スコア | 評価 |
|--------|-----------|------|
| **S** | 4.5〜5.0 | 卓越 |
| **A** | 3.5〜4.4 | 優秀 |
| **B** | 2.5〜3.4 | 良好 |
| **C** | 1.5〜2.4 | 発展途上 |
| **D** | 1.0〜1.4 | 要改善 |

> **注意:** 有効軸数が 4 未満の場合、総合評価は「保留 — 追加情報が必要」となります。

## ワークフロー

```
Phase 0: 研究者同定（名前・所属から正しい人物を特定）
Phase 1: サーベイ（Web 検索で情報収集）⏸️ エビデンス承認
Phase 2: 評価（6 軸 5 段階スコアリング）
Phase 3: レポート生成 ⏸️ 最終承認
```

## 設計方針

- **Evidence-Based**: すべてのスコアにエビデンス（出典 URL + 取得日）を紐付け
- **Confidence-Aware**: 証拠不足 ≠ 低評価。情報が不十分な軸は N/A として総合評価から除外
- **File-First**: 成果物はすべてファイルに保存（`evidence-dossier.md`, `evaluation.md`, `report.md`）
